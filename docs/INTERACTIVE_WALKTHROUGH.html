1. User Roles

This system supports multiple roles for different responsibilities:

Admin

Full system access, manage users & stores

B1 (Branch 1)

Create orders, manage items

B2 (Branch 2)

Orders, invoices, packing

B3 (Branch 3)

Supplier - fulfill orders

Accountant

Invoices & financial reports

2. Order Workflow

Orders follow a clear progression from creation to completion:

Draft
→
Submitted
→
Preparing
→
Ready
→
Shipped
→
Received
→
Completed
Orders can also be:
Cancelled
Key Point: Draft orders are only visible to the creator. You must SUBMIT the order for the supplier to see it.

3. Creating an Order (B1 Role)

1

Navigate to Orders

Click "Orders" in the left sidebar menu

2

Click "Create Order"

Click the blue "Create Order" button

3

Select Stores

Choose "From Store" (your store) and "To Store" (supplier B3)

4

Add Items

Search for items, enter quantities. Add as many items as needed.

5

Create & Submit

Click "Create Order", then click "Submit" to send to supplier

✓

Accept to proceed, or reject with a reason

📦

Start Preparing

🚚

Mark as Ready & Ship

When ready, mark order and hand off to requester

8. Common Questions

?

Q: Supplier can't see my order

A: Did you click SUBMIT? Draft orders are only visible to you.

?

Q: Can I edit after submitting?

A: No. Contact supplier to reject, then create a new order.

?

Q: How to cancel an order?

A: Draft = Delete button. Submitted = Cancel with reason.

?

Q: Notification bell not updating?

A: Refresh the page. Updates every 15 seconds.
